Drop transparent PNG renders of Nova here and the app uses them automatically:

  idle.png          (required for the PNG look; used as fallback for every state)
  happy.png  safe.png  concerned.png  talking.png  listening.png  thinking.png
  sleeping.png  appointment.png  fall_detected.png  emergency.png

Square-ish canvas, character centred, transparent background, ~800 px wide.
Without these files Nova is drawn as a vector heart.
